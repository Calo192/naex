1.3 Pozície: kde sa akcie spájajú

Šanca, že na danej pozícii leží akcia (náhodná karta v hre, náhodný variant), a šanca, že akcia na tej pozícii nájde partnera u náhodného suseda v náhodnom natočení (§6: spoj = rovnaký index, otočením 0↔3 a 1↔2).

PozíciaAkcia vľavoAkcia vpravoPartner pre akciu vľavoPartner pre akciu vpravo
0 (hore) 44 % → 40 % 45 % → 38 % 33 % → 28 % 44 % → 37 %
1 65 % → 64 % 64 % → 64 % 58 % → 57 % 60 % → 59 %
2 51 % → 50 % 55 % → 55 % 60 % → 59 % 58 % → 57 %
3 (dole) 21 % → 19 % 43 % → 35 % 44 % → 37 % 33 % → 28 %

Nové karty majú akcie hlavne v strede: 9 z 13 má okraje (0 alebo 3) zablokované na oboch stranách. Akcie na okrajových pozíciách starých kariet tak nájdu partnera menej často: vľavo na 0 a vpravo na 3 z 33 % na 28 %, vpravo na 0 a vľavo na 3 zo 44 % na 37 %. Stred (1, 2) ostáva okolo 58 %. Najviac to oslabí karty, ktoré majú dôležitú akciu na okraji. Je to malý posun, netreba ho riešiť, len vedieť o ňom pri ďalších kartách.
